# Prácticas de Procesamiento de Datos

Este repositorio reúne los ejercicios y ejemplos de código que voy realizando mientras estudio la materia Procesamiento de Datos.

## Cómo trabajo

Estudio los temas con los cuadernillos, pruebo y modifico el código en Visual Studio Code, y registro aquí mis avances. Uso OneNote para guardar explicaciones teóricas, dudas, respuestas y enlaces a otros materiales.

## Contenido

Voy a organizar las prácticas en carpetas por tema a medida que avance. En el código incluiré comentarios para recordar qué hace cada paso y por qué lo utilicé.

## Objetivo

Aprender a explorar, limpiar y procesar datos mediante la práctica, conservando un registro de lo que voy aprendiendo.
